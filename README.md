# 주일설교 사운드 직접 녹취 & A4 2장 편집 웹 프로그램

## 작동 방식
1. 사용자가 **유튜브 주소**와 **1~3대지 및 적용질문**을 입력합니다.
2. 서버가 `yt-dlp`와 `ffmpeg`로 유튜브 영상의 **사운드(오디오)**와 **설명란(제목/설교자/일자/성경구절)**을 추출합니다.
3. **Gemini API**가 사운드를 직접 듣고 녹취한 뒤, 목사님 대본 어조를 살려 **도입(3~4줄) + 1~3대지 요약(A4 1.5장 분량)**과 **상단 성경구절(A4 0.5장 이내)**을 편집합니다.
4. **PDF(A4 2장 자동맞춤)**, **한글(.hwp)**, **워드(.docx)** 3종 파일로 다운로드할 수 있습니다.
